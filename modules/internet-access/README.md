# Equinix Fabric Internet Access

Creates an `equinix_fabric_internet_access_service` and, in the same module, reads it back by UUID
(`equinix_fabric_internet_access_service` data source) and searches services (`equinix_fabric_internet_access_services`
data source, by name). The search runs after the create.

Please refer to the `internet-access` example for usage details.
